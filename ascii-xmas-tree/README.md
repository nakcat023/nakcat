# ต้นคริสต์มาสตัวอักษร

แอนิเมชันต้นคริสต์มาสแบบ ASCII art เขียนด้วย Python + numpy + pygame
มีไฟกะพริบบนต้น ดาวบนยอด กล่องของขวัญ หิมะตก ป่าสนสีน้ำเงิน และพลุหลายแบบ

ลูกเล่น
- แมวส้มนั่งข้างกล่องของขวัญ กระดิกหาง กะพริบตา คลิกแล้วร้องเหมียว (มีเสียง)
- นับถอยหลังถึงคริสต์มาสและปีใหม่บนฟ้า 10 วิสุดท้ายพลุแตกเป็นตัวเลข ถึงเวลาแล้วจุดพลุรัวปิดท้าย
- พลุรูปหัวใจ หน้าแมว ดาว และตัวอักษร (XMAS, JOY, LOVE, MEOW, เลขปี)
- ซานต้าขี่เลื่อนบินผ่านฟ้า และดาวตกเป็นครั้งคราว
- ไฟบนต้น 4 โหมด: หลากสี, สีทอง, ไล่สีรุ้ง, กะพริบตามจังหวะ

เวอร์ชันเว็บ (TypeScript + canvas) อยู่ที่ `src/xmas.ts` → `nakcat-site/xmas.html`

## วิธีที่ง่ายที่สุด

ดับเบิลคลิก `run.bat` ใน File Explorer จบ (เครื่องที่ยังไม่เคยติดตั้ง ไฟล์นี้จะติดตั้งให้เองครั้งแรก
ถ้าเครื่องมี uv จะใช้ uv ถ้าไม่มีจะใช้ Python ที่ลงไว้ในเครื่อง)

ใช้ `pygame-ce` แทน `pygame` ตัวเดิม เพราะ pygame ตัวเดิมยังไม่มีให้ลงบน Python 3.14
ในโค้ดยังเขียน `import pygame` เหมือนเดิม

## ติดตั้ง

ใช้ [uv](https://docs.astral.sh/uv/)

```
cd ascii-xmas-tree
uv venv --python 3.12 .venv
uv pip install --python .venv -r requirements.txt
```

หรือใช้ pip ธรรมดา

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

## รัน

```
.venv\Scripts\python xmas_tree.py
```

| ปุ่ม | ทำอะไร |
|---|---|
| Space | ยิงพลุเพิ่ม 1 ลูก |
| คลิกซ้าย | บนฟ้า: พลุแตกตรงจุดที่คลิก, บนแมว: แมวร้องเหมียว |
| L | เปลี่ยนโหมดไฟ |
| F | เต็มจอ / ออกจากเต็มจอ |
| Esc | ปิดโปรแกรม |

ตัวเลือกเพิ่ม

- `--seconds 8` รัน 8 วินาทีแล้วปิดเอง
- `--screenshot shot.png` เซฟเฟรมสุดท้ายเป็นรูปก่อนปิด
- `--seed 7` เปลี่ยนเลขสุ่มตั้งต้น ป่ากับของตกแต่งจะเปลี่ยนตำแหน่ง
- `--lights rainbow` เริ่มด้วยโหมดไฟที่เลือก (classic, warm, rainbow, beat)
- `--now "2026-12-24 23:59:45"` แกล้งทำเป็นว่าตอนนี้เป็นเวลานั้น ไว้ดูนับถอยหลังกับพลุปิดท้ายโดยไม่ต้องรอวันจริง
  (หน้าเว็บก็ทำได้: `xmas.html?now=2026-12-24T23:59:45`)

รันแบบไม่เปิดหน้าต่าง เอาไว้เช็กภาพ (PowerShell)

```
$env:SDL_VIDEODRIVER='dummy'; .venv\Scripts\python xmas_tree.py --seconds 8 --screenshot shot.png
```
