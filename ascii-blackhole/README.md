# หลุมดำกลืนโค้ด

แอนิเมชันตัวอักษร (ASCII art) เขียนด้วย Python + numpy + pygame-ce
ตัวอักษรทุกตัวบนจอมาจากซอร์สโค้ดจริงของ `blackhole.py` กับ `ascii-xmas-tree/xmas_tree.py`
หลุมดำกลืนตัวอักษรทั้งจอ ระเบิดออกมา แล้วตัวอักษรชุดเดิมไปเรียงตัวเป็นกาแล็กซี
หนึ่งรอบยาวประมาณ 67 วินาที จบแล้ววนกลับมาเริ่มใหม่เอง

## เรื่องในแต่ละช่วง

| ช่วง | เวลา | เกิดอะไรขึ้น |
|---|---|---|
| 1 ทะเลโค้ด | 0–3 วิ | ตัวอักษรเต็มจอไหลลงเป็นคอลัมน์ สีเขียวกับฟ้า แต่ละคอลัมน์เร็วไม่เท่ากัน หัวคอลัมน์สว่างกว่าหาง มีแถบ glitch เลื่อนเยื้องและกะพริบเป็นระยะ |
| 2 หลุมดำถือกำเนิด | 3–10 วิ | จุดดำโผล่กลางจอแล้วค่อย ๆ โต ตัวอักษรรอบ ๆ ถูกเลนส์ความโน้มถ่วงดันออกและบิดเป็นวง หลุมยังว่างเปล่า มีแค่วงแหวนแสงจาง ๆ ดิสก์และแสงสีจะค่อย ๆ เกิดในช่วง 3 ตามจำนวนตัวอักษรที่กลืนเข้าไป |
| 3 ดูดกลืน | 10–27 วิ | ตัวอักษรหลุดจากตาราง ตัวที่อยู่ใกล้หลุดก่อน แล้ววนเป็นเกลียวเข้าหลุม ยิ่งใกล้ยิ่งร้อน สีเปลี่ยนจากแดงเป็นส้มแล้วเป็นขาว ตัวที่วิ่งเร็วยืดเป็นเส้นและมีหาง หลุมโตขึ้นทุกครั้งที่กลืน ใกล้จบช่วงจอสั่นเบา ๆ พอโค้ดหายไปจากจอ ดาวจาง ๆ จะโผล่ขึ้นมาเป็นฉากหลัง (ดาวด้านหลังหลุมถูกเลนส์บิดอ้อมด้วย) หลุมหน้าตาแบบหลุมดำที่มีดิสก์: ดิสก์เส้นบางพาดหน้าหลุม โค้งสว่างใหญ่ด้านบน (ด้านหลังของดิสก์ที่แสงถูกบิดอ้อมขึ้นมา) โค้งเล็กด้านล่าง ตัวอักษรที่วนอยู่ด้านหลังหลุมก็ถูกยกขึ้นเป็นโค้งเหนือหลุมเหมือนกัน |
| 4 ยุบตัวและระเบิด | 27–32 วิ | หลุมหดเหลือจุดเดียว มืดสนิท 0.8 วิ ระหว่างนั้นมีวงแสงจาง ๆ หดเข้าหาจุดกลางจอ แล้วตูม: แสงวาบขาวทอง ลำแสงพุ่งออกรอบทิศ จอสั่น วงคลื่นแสงสีฟ้าขาววิ่งพ้นขอบจอ ตามด้วยวงสีส้ม เส้นแสงแนวนอนพาดกลางจอ และวงแหวนตัวอักษร ตัวอักษรทุกตัวที่ถูกกลืนพุ่งกระจายออกมา ตัวที่พุ่งเร็วยังขาวร้อน ตัวที่ช้าเย็นเป็นส้มแดง ส่วนหนึ่งค้างอยู่กลางจอเป็นแกนดาวสีทองที่เต้นเบา ๆ จนกาแล็กซีก่อตัว |
| 5 กาแล็กซี | 32–67 วิ | ตัวอักษรชะลอแล้วถูกดูดวนเป็นเกลียวจากวงกว้างหดเข้ามาเรียงตัวบนแขนก้นหอย 3 แขน วงในหมุนเร็วกว่าวงนอก แกนกลางขาวอมเหลือง แขนหลายสีเป็นหย่อม (ฟ้าเขียว ฟ้า ม่วง บานเย็น ชมพู) มีเมฆเนบิวลาจาง ๆ และดาวหลายสีระยิบระยับเป็นพื้นหลัง 2.5 วิสุดท้ายตัวอักษรบินกลับเข้าตารางแล้วเริ่มช่วง 1 ต่อ |

## วิธีที่ง่ายที่สุด

ดับเบิลคลิก `run.bat` ใน File Explorer ได้เลย
เปิดครั้งแรกบนเครื่องใหม่ ไฟล์นี้จะติดตั้งแพ็กเกจให้เอง ถ้าเครื่องมี uv จะใช้ uv ถ้าไม่มีจะใช้ Python ที่ลงไว้ในเครื่อง

โปรแกรมวาดภาพขนาด 1920x1080 ถ้าจอไม่ใหญ่กว่านี้ (เช่นจอ 1920x1080 พอดี ที่ใส่หน้าต่างพร้อม taskbar ไม่พอ) จะเปิดเต็มจอแทน กด Esc เพื่อออก

ใช้ `pygame-ce` แทน `pygame` ตัวเดิม เพราะ pygame ตัวเดิมยังไม่มีให้ลงบน Python 3.14
ในโค้ดยังเขียน `import pygame` เหมือนเดิม

## ติดตั้งเอง

ใช้ [uv](https://docs.astral.sh/uv/)

```
cd ascii-blackhole
uv venv --python 3.12 .venv
uv pip install --python .venv -r requirements.txt
```

หรือใช้ pip ธรรมดา

```
py -3 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

## รัน

```
.venv\Scripts\python blackhole.py
```

| ปุ่ม | ทำอะไร |
|---|---|
| Space | ข้ามไปช่วงถัดไป |
| R | เริ่มใหม่ตั้งแต่ช่วง 1 |
| คลิกซ้าย | ช่วง 1–3: สร้างหลุมดำเล็กตรงที่คลิก ดูดตัวอักษรใกล้ ๆ (ช่วง 1–2 หลุมระเหยไปเอง ตัวอักษรบินกลับเข้าตาราง ช่วง 3 หลุมเล็กถูกดึงไปรวมกับหลุมใหญ่) / ช่วง 5: ซูเปอร์โนวาเล็ก ๆ ตรงนั้น |
| P | หยุด / เล่นต่อ |
| + / - | เร็วขึ้น / ช้าลง (0.25x ถึง 4x) |
| L | เปิด / ปิดการวนรอบ (ปิดแล้วกาแล็กซีจะหมุนค้างไว้เรื่อย ๆ) |
| H | ปักแถบล่างไว้ตลอด / ซ่อน |
| F | เต็มจอ / ออกจากเต็มจอ |
| Esc | ปิดโปรแกรม |

แถบปุ่มควบคุมด้านล่างจอแสดง 10 วินาทีแรกแล้วค่อย ๆ หายไป กดปุ่มอะไรก็ได้หรือเลื่อนเมาส์ไปขอบล่างจอ แถบจะกลับมา
มุมขวาของแถบบอกว่าอยู่ช่วงไหน ความเร็ว FPS และจำนวนตัวอักษร

ตัวเลือกเพิ่ม

- `--start-at 30` กระโดดไปเริ่มที่วินาทีที่ 30 ของเรื่อง
- `--seconds 20` รันถึงวินาทีที่ 20 ของเรื่องแล้วปิดเอง
- `--screenshot shot.png` เซฟเฟรมสุดท้ายเป็นรูปก่อนปิด
- `--shots 5,25,50 --shot-dir รูป` เซฟรูปที่วินาทีเหล่านี้
- `--fast` ไม่รอเวลาจริง เดินเรื่องเฟรมละ 1/60 วิ (เอาไว้ทดสอบ)
- `--no-auto` ปิดการลดจำนวนตัวอักษรอัตโนมัติ
- `--seed 7` เปลี่ยนเลขสุ่มตั้งต้น ฝนโค้ด รูปกาแล็กซี และสีจะเปลี่ยนไป

ตอนปิดโปรแกรม (ถ้ารันจาก terminal) จะพิมพ์ FPS เฉลี่ยของแต่ละช่วงออกมาให้

รันแบบไม่เปิดหน้าต่าง เอาไว้เช็กภาพ (PowerShell)

```
$env:SDL_VIDEODRIVER='dummy'; .venv\Scripts\python blackhole.py --fast --seconds 50 --shots 5,12,25,38,50
```

## ปรับค่าใน CONFIG

ค่าที่ปรับได้อยู่ส่วน `CONFIG` บนสุดของ `blackhole.py` แก้ตัวเลขแล้วรันใหม่ได้เลย

| อยากได้ | แก้ค่านี้ |
|---|---|
| เปลี่ยนความยาวแต่ละช่วง | `PHASE_SECONDS` (ทะเลโค้ด, หลุมเกิด, ดูดกลืน, ระเบิด, กาแล็กซี) ถ้ายืดช่วง 3 ให้ยืด `RELEASE_SPAN` ตามด้วย ไม่งั้นจะกลืนหมดเร็วแล้วจอว่างนาน |
| ตัวอักษรมากขึ้น / น้อยลง | `CELL_W`, `CELL_H` ช่องเล็กลง = ตัวอักษรมากขึ้น (ตอนนี้ 9x16 ได้ 14,697 ตัว) และ `MAX_PARTICLES` เพดานจำนวน |
| เครื่องช้า | ระบบจะปิดเงาหางก่อน แล้วลดตัวอักษรครั้งละ 15% แต่ไม่ต่ำกว่า `MIN_PARTICLES` ปิดได้ที่ `AUTO_REDUCE` |
| ฝนโค้ดเร็ว/ช้า | `RAIN_SPEED`, `HEAD_SPEED`, `HEAD_TAIL` (หางยาว) |
| เลนส์รอบหลุมบิดแรงขึ้น | `LENS_FACTOR`, `LENS_TWIST` |
| ดิสก์รอบหลุมสว่าง/จาง | `DISK_BRIGHTNESS` (0–1) สีของดิสก์อยู่ที่ `COLORS["disk"]` (ร้อน → เย็น) หน้าตาที่เหลืออยู่ในฟังก์ชัน `make_disk_textures` |
| ตัวอักษรที่โคจรในดิสก์ | `DISK_SPARKS` จำนวน (0 = ไม่มี), `DISK_SPIN` ความเร็วโคจร |
| โค้งตัวอักษรเหนือหลุมสูงขึ้น | `DISK_LENS` |
| หลุมใหญ่ขึ้น | `HOLE_BIRTH_RADIUS` (ตอนจบช่วง 2), `HOLE_MAX_RADIUS` (ตอนกลืนครบ) |
| ดูดแรงขึ้น / วนนานขึ้น | `GM` แรงดึง, `DRAG` ยิ่งน้อยยิ่งวนหลายรอบก่อนตกหลุม, `TANGENTIAL` ความเร็ววนตอนหลุด |
| ดิสก์เอียงมาก/น้อย | `DISK_TILT` (1 = ไม่เอียง, ยิ่งน้อยยิ่งแบน) |
| ตัวอักษรยืดเป็นเส้นง่ายขึ้น | ลด `SPAGHETTI_SPEED` และเพิ่ม `TAIL_COUNT` |
| ระเบิดแรงขึ้น | `BLAST_SPEED`, `SHOCK_SPEED`, `BLAST_SHAKE` จอสั่นกี่พิกเซล |
| แสงตอนระเบิด | `BLAST_FX = False` กลับไปเป็นแบบเดิม (ไม่มีวงคลื่นแสง เส้นแสงแนวนอน แกนเรือง และตัวอักษรระเบิดเป็นสีเดียว), สีอยู่ใน `COLORS["shock"]`, `["shock2"]`, `["streak"]`, `["remnant"]`, `["rays"]` |
| ลำแสง / แกนดาวหลังระเบิด | `BLAST_RAYS` ความแรงลำแสง (0 = ไม่มี), `BLAST_CORE` สัดส่วนตัวอักษรที่ค้างกลางจอเป็นแกนดาว (0 = กลางจอว่าง) |
| ดาวช่วงดูดกลืน | `SWALLOW_STARS = False` ปิด (ช่วงดูดกลืนพื้นหลังจะดำล้วนเหมือนเดิม) |
| หลังระเบิดลอยกระจายนานขึ้นก่อนดูดเป็นกาแล็กซี | `GALAXY_GATHER_DELAY` (วินาที), `BLAST_COOL` ยิ่งมากตัวอักษรยิ่งเรืองนาน |
| ตอนดูดเข้าเป็นกาแล็กซี หมุนมาก/น้อย | `GALAXY_SWIRL_TURNS` จำนวนรอบที่วน (0 = พุ่งเข้าตรง ๆ), `GALAXY_SWIRL_SECONDS` ใช้เวลาวนกี่วิ, `GALAXY_SWIRL_SPREAD` เริ่มวนจากวงกว้างแค่ไหน |
| กาแล็กซี | `GALAXY_ARMS` จำนวนแขน (2–4), `GALAXY_TURNS` แขนวนกี่รอบ, `GALAXY_SPIN` ความเร็วหมุน, `GALAXY_TILT` ความเอียง |
| หลุมดำเล็ก / ซูเปอร์โนวา | `MINI_CAPTURE`, `MINI_LIFE`, `SUPERNOVA_RADIUS`, `SUPERNOVA_KICK` |
| แสงเรืองมาก/น้อย | `GLOW_GAIN` |
| สีกาแล็กซี / เมฆเนบิวลา / ดาว | `COLORS["arms"]` สีแขน (ไล่ผ่านหลายสี แต่ละตัวได้สีตามหย่อมเมฆที่มันอยู่), `COLORS["nebula"]` สีเมฆพื้นหลัง, `COLORS["nebula_base"]` สีพื้น (ตั้งเป็น 0 ได้พื้นดำ), `COLORS["stars"]` สีดาว, `BG_STARS` จำนวนดาว |
| สี | `COLORS` เป็นจุดสี RGB (0–1) ที่ไล่สีผ่านกัน เช่น `"arms"` ไล่จากฟ้าไปม่วง |

## ทำงานยังไง (ย่อ ๆ)

- ตัวอักษรทุกตัวคือ particle หนึ่งตัว เก็บตำแหน่ง ความเร็ว ตัวอักษร สี และสถานะไว้ใน numpy array ชุดเดียว
  คำนวณทีเดียวทั้ง array ไม่วนลูปทีละตัวใน Python
- ฟิสิกส์เดินทีละ 1/120 วินาทีเสมอ (fixed timestep) เครื่องเร็วหรือช้า ผลก็เหมือนกัน
- แรงดึงของหลุมเป็นแบบ 1/r² มีระยะต่ำสุดกันไม่ให้พุ่งแรงเกิน ตอนหลุดจากตารางแต่ละตัวได้ความเร็ววนรอบหลุมด้วย แล้วแรงหน่วงทำให้ค่อย ๆ วนเป็นเกลียวเข้าไป
- เลนส์ความโน้มถ่วงใช้สูตรเลนส์จุด `r' = (r + √(r² + 4E²)) / 2` แล้วบิดมุมเพิ่มตามระยะ
- แขนกาแล็กซีเป็นเกลียวลอการิทึม `r = a·e^(bθ)` แต่ละตัวมีสปริงดึงไปหาจุดของตัวเองบนแขน จุดนั้นหมุนรอบกลาง วงในเร็วกว่าวงนอก
- ตอนเปิดโปรแกรมสร้างภาพตัวอักษรทุกตัว × ทุกสี × 12 ระดับความสว่างไว้ก่อน (ประมาณ 54,000 ภาพเล็ก ใช้เวลาราว 0.3 วิ)
  ระหว่างเล่นแค่หยิบภาพมาแปะด้วย `fblits` แบบบวกแสง (additive) ไม่ต้อง render ฟอนต์อีก
- แสงเรืองวาดลงบัฟเฟอร์เล็ก 1/8 ของจอ เบลอโดยย่อแล้วขยาย แล้วบวกลงจอ ช่วงดูดกลืนกับกาแล็กซีบัฟเฟอร์ค่อย ๆ จางแทนการล้าง เลยเกิดหางแสงตามหลังตัวที่วิ่ง
